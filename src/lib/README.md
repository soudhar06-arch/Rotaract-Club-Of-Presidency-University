# Library Directory (`src/lib/`)

This directory houses core infrastructure utilities, database client configurations, auth utilities, and Zod validation schemas.

## Structure

- `utils.ts` - General utility functions (e.g. `cn` class merger).
- `validators.ts` - Shared Zod validation schemas for forms and API requests.
- `supabase/` - Supabase client initialization (configured for future data layer).
