RCPU — EVENT DETAILS SOURCE FILE
File name: Events even Details.txt

PURPOSE
This file contains the authoritative descriptive information for conducted/historical events currently documented in the Event Reports PDF.
The public event gallery should use the Google Drive folder name as the event title and use this file to find the corresponding event description and metadata.
For new or updated events, the Admin Portal is the management interface. Do not require source-code changes just to add or edit an event description.

DATA RULES
1. One EVENT block represents one event.
2. Match an event to its Google Drive folder using the event title, with safe normalization for capitalization, whitespace and punctuation.
3. Do not use fuzzy matching when it could cause two different events to be confused.
4. If an event exists in Google Drive but has no matching block here, allow the Admin Portal to add/edit its description.
5. Never invent a description when no source description exists.
6. Admin-entered updates should take precedence over the imported historical description for that event.
7. Keep the existing Google Drive image architecture: one child folder = one event; all images in that folder belong to that event.
